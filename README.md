# ZoneZeroAdvancements — 零號禁區成就

Minecraft 1.21.1 / NeoForge 21.1 / Java 21。目標為純伺服器端，未新增物品、方塊或自訂網路封包。原版客戶端成就資料由伺服器同步。專屬圖示另使用可選資源包；**目前為開發測試版，尚未完成正式伺服器實測。**

## 開發中已接入的判定
- 事件型死亡／殭屍擊殺：新計數，不讀舊原版統計；保存於伺服器玩家資料。四種原版感染者與 28 種禍亂亡靈由可擴充實體標籤控制；不包含玩家屍體、投射物、召喚附屬物。
- Pufferfish Skills 0.19.2：透過唯讀 getSpentPoints，分類 zonezero:genetics / tacz_skill_tree:tacz。首次讀取現有已花點數為基準，之後只按新增加的實際投入點數判定。若玩家原本已點滿，不會補發；正常重置技能時基準降低，成就不撤銷。因不修改原技能，舊玩家必須有後續新投入才可能達成高門檻。
- 七個探索區：主世界水平直線距離，原點 (0,0)，上限為 400、800、1200、1600、2000、2400、3001 格；超過 3001 格不算。與 2026-11-25 十四區腳本成對映射；不修改難度、掉落或生成設定。首次登入不直接補發所在地區，移動後才判定。
- 瓶蓋：直接盤點物品持有量，首次登入的既有持有量作基準。已核對物品 ID，且依 2026-11-06 已確認的經濟設定，預設 1 個瓶蓋盒等於 50 個瓶蓋；計算成就時不更動物品。檔案 config/zonezero_advancements.properties 的 bottleCapBoxValue 可設定面額，0 表示不換算。設定改變時重新建立持有量基準，避免誤發。
- 隱藏成就：死亡原因、洞穴蜈蚣、徒手及近戰、殘血擊殺、同歸於盡（同一對敵手 5 秒內）、第七區討伐、六種乖乖放置、午夜進食、酒類完成飲用、已列入標籤的醫療用品完成使用、連續在線 8 小時、和平主義者（存活且未擊殺生物 24,000 tick）、技能雙滿及核心全達成。
- 近戰、酒類及醫療用品由資料包 item tags 控制；武器/藥物不在已驗證清單時不會隨便計數。食物隱藏成就只判定實際進食時刻，不保存食物種類。

## 尚未接入外部模組的事件
救援／被救、倒地死亡、TaCZ 爆頭、建立庇護所、使用庇護所傳送石、因藥草錯誤使用造成血栓均保留完整成就定義與伺服器側事件橋接，但**未宣稱可以自動解鎖**。需在對應模組的成功事件實際接入後才能啟用。橋接函式：

```java
ZoneZeroAdvancements.recordExternal(serverPlayer, "revived");
```

可用事件：revived, revive_other, downed_death, gun_headshot_kill, shelter_create, shelter_teleport, low_health_teleport, herb_thrombosis, medical_use（僅限未經物品完成使用事件計數的特殊醫療行為，避免重複）。不提供公共指令或客戶端自行回報的方式。實際事件接入要另外確認來源及成功條件。

## 編譯與測試
安裝 Java 21 / Gradle 8.10.2 / Python 3，執行：
```sh
gradle clean build
```
若 python 指令不存在，設定 PYTHON=python3。會生成 188 份 advancement JSON（187 項 + 根節點），驗證數量、唯一名稱、描述、父節點、圖示連結、七區距離邊界與技能起始基準，並產出 build/libs/*.jar 與 build/distributions/ZoneZeroAdvancements-Icons-Batch01.zip。GitHub Actions 同時提供這兩個測試產物。編譯通過不等於遊戲連線與所有事件測試通過。

測試請使用獨立世界，不要直接安裝到正式伺服器。確認死亡重生、重新登入、伺服器重啟紀錄保留；測試七區邊界、殭屍掉落機制不變、Pufferfish 資料唯讀、隱藏成就未完成前不可見、資源包有無載入均可連線。
