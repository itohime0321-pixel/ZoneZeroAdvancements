# ZoneZeroAdvancements

零號禁區專屬成就模組，目標 Minecraft 1.21.1 / NeoForge / Java 21。

規劃三個成就系列：

- 死亡次數：1、10、30、50、75、100、150、200、250、300、350、400、450、500、550、600、650、700、750、800、850、900、950、1000 次。
- 基因技能：實際投入 1 點、10 點、每 10 點直到滿點。
- 槍械技能：實際投入 1 點、10 點、每 10 點直到滿點。

## 開發原則

- 不修改原有技能、傷害、經濟與掉落邏輯。
- 語言採用台灣繁體中文，成就命名包含動漫／電影致敬及廢土黑色幽默。
- 舊玩家歷史死亡數須透過原版統計補發；技能點數須直接讀取正式使用的技能資料來源，避免虛報。
- 技能點滿上限及技能模組整合方式待比對正式運行的 JAR／技能樹設定後確定。
- 不以管理員手動指令或持有血清數量代替技能投入判定。

## 開發狀態

目前為需求及專案初始化階段，尚未提供可安裝的 JAR。請勿將本儲存庫內容視為已完成的遊戲模組。
