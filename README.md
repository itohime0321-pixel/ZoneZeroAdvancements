# ZoneZeroAdvancements — 零號禁區成就

Minecraft 1.21.1 / NeoForge 21.1 / Java 21。目標為純伺服器端，未新增物品、方塊或自訂網路封包。原版客戶端成就資料由伺服器同步。專屬圖示另使用可選資源包；**目前為開發測試版，尚未完成正式伺服器實測。**

## 0.2.1 聊天室成就公告
- 所有 202 項零號禁區成就首次完成時，在聊天室全服廣播「玩家 達成『成就名稱』。介紹與解鎖條件」單則訊息（遊戲內使用全形「」）；不強制換行，長介紹由 Minecraft 聊天欄自然折行。保留右上角原版通知。
- 隱藏成就只於完成後公開；根節點不廣播。既有進度不會在普通重登入時重新公告，其他模組的公告不受影響。
- 尊重原版 `/gamerule announceAdvancements true`；若設為 false 則不廣播。管理員手動 grant 同樣會公告。資源包未改動，0.2.0 的資源包仍可沿用。

## 開發中已接入的判定
- 事件型死亡／殭屍擊殺：新計數，不讀舊原版統計；保存於伺服器玩家資料。四種原版感染者與 28 種禍亂亡靈由可擴充實體標籤控制；不包含玩家屍體、投射物、召喚附屬物。
- Pufferfish Skills 0.19.2：透過唯讀 getSpentPoints，分類 zonezero:genetics / tacz_skill_tree:tacz。首次讀取現有已花點數為基準，之後只按新增加的實際投入點數判定。若玩家原本已點滿，不會補發；正常重置技能時基準降低，成就不撤銷。因不修改原技能，舊玩家必須有後續新投入才可能達成高門檻。
- 七個探索區：主世界水平直線距離，原點 (0,0)，上限為 400、800、1200、1600、2000、2400、3001 格；超過 3001 格不算。與 2026-11-25 十四區腳本成對映射；不修改難度、掉落或生成設定。首次登入不直接補發所在地區，移動後才判定。
- 瓶蓋：直接盤點物品持有量，首次登入的既有持有量作基準。已核對物品 ID，且依 2026-11-06 已確認的經濟設定，預設 1 個瓶蓋盒等於 50 個瓶蓋；計算成就時不更動物品。檔案 config/zonezero_advancements.properties 的 bottleCapBoxValue 可設定面額，0 表示不換算。設定改變時重新建立持有量基準，避免誤發。
- 隱藏成就：死亡原因、洞穴蜈蚣、徒手及近戰、殘血擊殺、同歸於盡（同一對敵手 5 秒內）、第七區討伐、六種乖乖放置、午夜進食、酒類完成飲用、已列入標籤的醫療用品完成使用、連續在線 8 小時、和平主義者（存活且未擊殺生物 24,000 tick）、技能雙滿及核心全達成。
- 近戰、酒類及醫療用品由資料包 item tags 控制；武器/藥物不在已驗證清單時不會隨便計數。食物隱藏成就只判定實際進食時刻，不保存食物種類。

## 外部事件整合（待遊戲實測）
以可選 Mixin 觀察以下已檢查的模組版本；缺少模組或目標程式結構不符時跳過對應橋接，不更動其他模組行為。
- PersonalShelter 1.0.9：只在私人庇護所建立方法回傳成功時記錄。
- ZoneZeroTeleport 1.0.4：只在成功傳送並消耗傳送石時記錄（包含已綁定的分區傳送石）；剩餘生命值未滿一顆心時另記殘血撤離。首次及第十次分別解鎖。
- Meds and Herbs 1.2.1：在長春花的藥效函式執行前後比對，無內出血且實際新增或延長血栓才記錄。不修改藥效持續時間。

- BleedOut 1.2.0（原繁中版及零號禁區倒地護甲修正版）：於正常救援完成時讀取實際救援者 UUID，確認倒地解除、被救者存活才記錄。中斷、尚未完成、OP 救援指令均不計入。倒地死亡於 BleedOut 清除標記前擷取，再由 NeoForge 未取消的死亡事件確認；一般倒地不算死亡。
- TaCZ 1.1.8 hotfix-r7 / 1.2.0（已核對兩份零號禁區修正版）：讀取伺服器端 EntityKillByGunEvent 的爆頭旗標，並與同一玩家、同一受害者、同一遊戲刻、同一實際死亡傷害來源比對。避免爆頭未擊殺、屍體、爆炸傷害、重複事件與客戶端回報誤發；無 TaCZ 時安全停用。

所有外部成就均已具備事件橋接程式，尚待使用各模組完整遊戲實測。橋接函式：

```java
ZoneZeroAdvancements.recordExternal(serverPlayer, "revived");
```

可用事件：revived, revive_other, downed_death, gun_headshot_kill, shelter_create, shelter_teleport, low_health_teleport, herb_thrombosis, medical_use（僅限未經物品完成使用事件計數的特殊醫療行為，避免重複）。不提供公共指令或客戶端自行回報的方式。實際事件接入要另外確認來源及成功條件。

## 編譯與測試
安裝 Java 21 / Gradle 8.10.2 / Python 3，執行：
```sh
gradle clean build
```
若 python 指令不存在，設定 PYTHON=python3。會生成 203 份 advancement JSON（202 項 + 根節點），驗證數量、唯一名稱、描述、父節點、圖示連結、七區距離邊界、技能起始基準、滿月時段、連殺時間窗口與新增血栓判定，並產出 build/libs/*.jar 與 build/distributions/ZoneZeroAdvancements-Icons.zip。GitHub Actions 先編譯及驗證資料，再以隔離的 NeoForge 1.21.1 專用伺服器啟動測試，確認實際載入 203 個定義並正常停止。這項啟動測試不包含完整零號禁區模組組合，也不代表玩家連線與所有外部事件已實測。

測試請使用獨立世界，不要直接安裝到正式伺服器。確認死亡重生、重新登入、伺服器重啟紀錄保留；測試七區邊界、殭屍掉落機制不變、Pufferfish 資料唯讀、隱藏成就未完成前不可見、資源包有無載入均可連線。

新增實測清單：成功與中斷的傳送、殘血門檻、首次與第十次傳送、已存在/首次建立的私人庇護所、正常治療與錯誤長春花使用、既有血栓未改變、沒有外部模組時啟動。歌曲成就需測試村民死因的歸屬、50 隻不死連殺、200/201 刻連殺邊界、下雨與躲雨、滿月與普通夜間、七區完成與重新登入、高處落地與原地登入。

倒地救援實測：正常救起、取消救援、管理員強制救起、倒地但未死亡、倒地逾時／二次攻擊死亡；TaCZ 實測：爆頭非致命、致命身體命中、致命爆頭、同一隻生物重複命中，以及兩種版本分別測試。
